# Vigenere-Squad

## Présentation du projet

Vigenere-Squad est un projet de cryptanalyse utilisant
une architecture multi-agents.

Son objectif est d'analyser et de déchiffrer différents
chiffrements classiques grâce à des outils cryptographiques
déterministes et à la collaboration entre plusieurs agents IA.

## Objectifs

- Identifier les méthodes de chiffrement.
- Analyser les textes chiffrés.
- Détecter les clés possibles.
- Déchiffrer les messages.
- Expliquer les résultats de manière pédagogique.

## Technologies

- Python
- Intelligence artificielle
- Cryptanalyse
- Tests automatisés

## Organisation

- agents/ : agents spécialisés
- scripts/ : outils et programmes Python
- tests/ : tests automatisés
- data/ : jeux de données
- docs/ : documentation
